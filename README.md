# Scrapling x402 Data Store (MCP Server)

Pay-per-call crypto, DeFi, stock and e-commerce data for AI agents. Free dataset previews, plus paid scrapes and datasets in USDC on Base via x402.

## Connect
MCP endpoint (Streamable HTTP):
https://cornhusk-rely-preformed.ngrok-free.dev/mcp

## Tools
- list_datasets (free) - see available data feeds
- preview_dataset (free) - sample rows from a feed
- scrape_url (paid) - scrape any URL, pay per call in USDC
- buy_dataset (paid) - buy a full dataset in USDC

## Payments
x402 protocol, USDC on Base, Polygon or Arbitrum.
Listed on x402scan: https://www.x402scan.com/server/1b76cf53-526e-48df-a7e7-2c777e14354a
